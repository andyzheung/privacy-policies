闪念隐私政策

生效日期：2026年11月01日

个人信息处理者：张文博

欢迎使用闪念。本隐私政策由张文博（以下简称“我们”）制定，说明闪念如何处理你的个人信息。

闪念是一项在设备本机记录短句笔记的桌面元服务。当前版本不提供云端同步、账号体系或语音转写服务。

一、我们如何收集和使用你的个人信息

为提供笔记记录与展示功能，闪念仅在你主动输入或操作时处理以下信息，并保存在你的设备本机：

信息类别具体信息使用目的处理方式
笔记内容你记下的文字正文、创建时间、笔记状态创建、展示和编辑你的笔记；在桌面服务卡片展示最近记录与当日条数加密后本机保存
时间线索从笔记文本中本机识别出的时间词（如“周六下午”）在卡片和详情页作为文字记号展示本机保存
笔记关联信息本机计算的笔记之间的关联分数在详情页展示可能相关的笔记本机保存
服务卡片状态卡片尺寸、展示状态、必要的本机标识及最近使用时间在桌面正确展示服务卡片；在“隐私与数据”页展示真实的条数与访问统计本机保存

闪念不要求你注册账号，也不收集姓名、身份证号、支付信息、精确位置、通讯录、相机、麦克风或短信内容。当前版本没有语音输入功能，不申请也不使用麦克风权限。

二、设备权限调用

闪念当前仅声明“振动”权限，用于你在服务内完成记录等操作时提供短暂的本机触感反馈。该权限不用于提醒、系统通知或向他人发送消息。你可以在系统设置中管理该权限；关闭后，核心的记录与查看功能仍可使用，仅触感反馈不可用。

三、信息存储、共享和传输

你的上述信息保存在设备本机。当前版本不自建服务器、不联网传输该等信息，也不向第三方共享、转让、公开披露这些信息。

闪念不接入广告、统计、支付、推送或社交类第三方 SDK，不存在第三方 SDK 收集你的个人信息的场景。

当你主动使用导出功能时，闪念会将你选择导出的笔记以 Markdown 文件写入你在系统保存面板中指定的位置；导出后的保存、分享或删除由你自行决定和管理。

四、信息存储地点及期限

信息默认存储在你当前设备的闪念应用数据区域（笔记正文加密保存）。除非你主动删除相关内容、卸载服务，或系统清除该服务数据，我们会在实现上述功能所需期间保存。你可以在服务内“隐私与数据”页删除单条笔记或一键清空全部笔记。

五、管理你的个人信息

你可以在闪念服务内查看、编辑或删除笔记，在“隐私与数据”页查看本地数据统计（总条数、最近访问时间）、导出全部笔记为 Markdown 文件，或一键清空全部笔记。你也可以通过系统设置清除闪念数据或卸载闪念，以删除本机数据。

如需就个人信息处理提出查询、更正、删除、撤回同意、投诉或其他请求，请发送邮件至：andyzheung@aliyun.com。我们会在核实请求后依照适用法律处理。

六、未成年人保护

闪念不面向不满十四周岁的儿童提供专门服务。若你是未成年人，请在监护人指导下使用。若我们发现未经监护人同意处理了儿童个人信息，将依法尽快删除或采取其他适当措施。

七、如何联系我们

联系邮箱：andyzheung@aliyun.com

八、本政策的更新与生效

若闪念的个人信息处理方式、权限或第三方 SDK 情况发生实质变化，我们会在实施前更新本政策并发布新版本。

本政策生效日期：2026年11月01日。
