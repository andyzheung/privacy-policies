一、服务内容

闪念是一项运行于 HarmonyOS 的桌面元服务，用于在设备本机记录和查看短句笔记。主要功能包括：

  1. 在详情页输入并保存一句话笔记，无需先整理标题、文件夹或标签；
  2. 在桌面服务卡片展示最近记录与当日条数；
  3. 从你的笔记文本中本机识别时间词，并在卡片与详情页作为文字记号展示；
  4. 在详情页展示可能相关的笔记（本机计算）；
  5. 在“隐私与数据”页查看本地数据统计、导出笔记为 Markdown 文件、删除单条或清空全部笔记。

本服务不提供云端同步、账号体系、语音输入或语音转写，也不是提醒、闹钟、系统通知、短信或电话服务。时间线索仅是文字记号，本服务不会在识别到的时间点响铃、弹窗或推送任何通知。

如你录入涉及他人的信息，应已取得相应授权，并自行承担由此产生的责任。

三、本地数据与导出

笔记内容（加密保存）、时间线索、关联信息和卡片状态默认保存在你的设备本机。我们不提供账号、云同步或数据备份服务。

你可以在服务内编辑或删除笔记，或在“隐私与数据”页一键清空全部笔记；卸载本服务或在系统设置中清除其数据，可能导致本地数据无法恢复。你主动导出的 Markdown 文件会保存到你在系统保存面板中选择的位置，导出后的保管、分享和删除由你自行决定。

2. 关于数据保管与服务容量

本服务将数据保存在设备本机，无云端备份。设备丢失、损坏、重置、卸载服务或清除数据都可能导致笔记永久丢失，请自行使用导出功能备份重要内容。受本机存储方式限制，单条笔记有长度上限、笔记总量有上限，超出时最早写入的笔记会被丢弃以腾出空间；请定期导出你希望长期保留的内容。

3. 关于内容准确性
